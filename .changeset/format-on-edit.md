Add the format-on-edit module to medium and full, where detection finds prettier, biome or ruff; elsewhere `init` leaves it out and prints why, as it now does for every module it leaves out. Its hook runs after each Edit, Write or MultiEdit of a file inside the project: the formatter, then the linters `.archkeeper/config.json` records (prettier, else biome, plus eslint for TS/JS; `ruff format`, then `ruff check --fix`, for Python), then any extra `commands`, each an argument array the file's path is appended to. `init` records the tools it detects as the module's `formatters` and `linters` when the config sets neither list, and never changes a value the config has. Tools come from the project itself: a Node.js tool's own bin in `node_modules`, run with the Node.js that runs the hook, and ruff from `.venv` or PATH; never npx, a download, a shell, npm or a `.cmd` or `.bat` shim. Formatting is silent; what the linters leave goes back to Claude, cut to 40 lines. A tool that is not installed is skipped, with a hint that shows once on the machine. Module options can now also be a number or a list of commands, and a module's `when` can name detected `tools`. With `.claude` linked to a folder outside the project, init now refuses unless `format-on-edit` is left out as well.
