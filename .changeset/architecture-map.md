Add the architecture-map module to medium and full. `init` now writes `docs/architecture.md` where the project has none, and never touches it again: the detected stack, a table of the folders `git ls-files` lists (two levels deep, 40 rows at most, with build, vendor and `.archkeeper/` folders left out) whose Purpose column Claude fills in, the entry points that `package.json` (`bin`, `main`, `exports`) and `pyproject.toml` (`[project.scripts]`) declare, each value in a code span and none over 100 characters, and an empty index block reserved for a later version. `git ls-files` reads only git's index, so it runs no filter program and fetches nothing; without git or a repository, the table asks for `/update-map` instead. The new `/update-map` skill brings the map up to date after a module, package, command or shared util is added or removed, and may run `git ls-files` without a prompt, nothing else. An AGENTS.md block tells agents to check the map before creating anything and to update it afterwards. With `.claude` linked to a folder outside the project, init now refuses unless `architecture-map` is left out as well.
