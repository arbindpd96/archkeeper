Add the feature-memory module to every preset and the knowledge module to medium and full. `init` now writes a feature memory template (`docs/features/_template/MEMORY.md`) and a mistakes log (`docs/mistakes.md`), plus, in medium and full, a decision log (`docs/decisions.md`), an ADR template (`docs/adr/0000-template.md`) and a glossary (`docs/glossary.md`); each doc is written only where the project has none, and never touched again. With `.claude` linked to a folder outside the project, init now refuses unless the modules that write under `.claude` (safety, feature-memory and knowledge) are all left out.
