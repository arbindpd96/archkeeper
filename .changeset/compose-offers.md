`init` now offers Superpowers and Spec Kit, off by default, and only prints how to add them. Right after the preset, an interactive run asks whether to add Superpowers, Spec Kit or both, defaulting to no; the new `--with superpowers,speckit` flag (either name or both) answers in a scripted run, and `--yes` alone means no. The answer, a no included, goes to `compose` in `.archkeeper/config.json`, so a later run reuses it without asking, as it does the preset. A yes prints the exact commands under Next steps: `claude plugin install superpowers@claude-plugins-official --scope project` for Superpowers, and `uv tool install specify-cli`, then `specify init --here --integration claude` for Spec Kit, with a warning never to pass `--force` to `specify init` without reading `specify init --help`. Nothing is run, installed or downloaded. `modules/compose.json` records the versions known to work (Superpowers 7.0.0, Spec Kit 1.2.1), their commands, and the skill names and prefixes the kit's own skills keep clear of. The `--json` output now includes the compose choice.
