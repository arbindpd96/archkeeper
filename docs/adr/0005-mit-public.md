# ADR-0005: MIT licence; public repository from the first commit

- Status: accepted
- Date: 2026-10-09
- Deciders: owner

## Decision

MIT licence. `github.com/arbindpd96/claude-codekit` is public from day one.

## Consequences

- Work in progress is visible. The README must say clearly that the project is pre-release until v0.1 is tagged.
- No secrets, internal URLs or personal data in commits. The secret-blocker hook (v0.1) also protects this repo.
- Launch (handoff §10) is a "v0.x release + announcement" moment, not a private-to-public flip.
