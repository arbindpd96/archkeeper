=== AGENTS.md
<!-- acmekit:begin agent-rules -->
Rules for AI coding agents, such as Claude Code, Codex, Cursor, Gemini CLI and Copilot, in this repository.

## Principles

1. **Think before coding.** State your assumptions. When a request is ambiguous, offer options or ask.
2. **Simplicity first.** Write the least code that solves the problem. No speculative features or abstractions.
3. **Surgical changes.** Touch only what the task needs. Never refactor unrelated working code.
4. **Goal-driven.** Define what "done" means, such as the tests passing, and verify it yourself before you report.

## Before creating anything new

1. Search the codebase for code that already does the job.
2. Reuse or extend it. Never duplicate it.
