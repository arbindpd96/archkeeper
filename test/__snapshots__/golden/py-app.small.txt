=== AGENTS.md
<!-- acmekit:begin agent-rules -->
Rules for AI coding agents, such as Claude Code, Codex, Cursor, Gemini CLI and Copilot, in this repository.

## Principles

1. **Think before coding.** State your assumptions. When a request is ambiguous, offer options or ask.
2. **Simplicity first.** Write the least code that solves the problem. No speculative features or abstractions.
3. **Surgical changes.** Touch only what the task needs. Never refactor unrelated working code.
4. **Goal-driven.** Define what "done" means, such as the tests passing, and verify it yourself before you report.

## Before creating anything new

1. Search the codebase for code that already does the job.
2. Reuse or extend it. Never duplicate it.

## Commands

| Command | What it does |
| --- | --- |
| `pytest` | Run the tests |
| `ruff check .` | Lint |
| `ruff format .` | Format |
<!-- acmekit:end agent-rules -->

<!-- acmekit:begin feature-memory -->
## Feature memory

Each feature keeps its working memory in `docs/features/<feature>/MEMORY.md`: the goal, decisions, progress and next step, so any session can resume it.

- Before changing code, read the active feature's MEMORY.md fully. If you do not know which feature is active, ask, and offer `/new-feature <name>` to start one.
- After an important decision, append it to **Decisions** with the date and the reason.
- Before ending a session, or when the context grows large, update **Done** and **Next step** (`/handoff` does both).
- Never contradict a recorded decision without asking the user first.
- Record approaches that failed in `docs/mistakes.md`, so nobody tries them again.
<!-- acmekit:end feature-memory -->

<!-- acmekit:begin safety -->
## Safety guards

Hooks guard this repository unless its config opts one out. guard-bash denies destructive shell commands and asks before irreversible ones. guard-secrets denies likely secrets in written files and asks before edits to `.env` files. When a guard blocks a call, change the approach; never work around it.

- Native deny rules back the guards and still apply when a hook cannot run, such as when Node.js is missing.
- Deny rules match on the command prefix only, so the guards are the fine-grained layer. Unless opted out, `Bash(rm -rf:*)` denies every command that starts with `rm -rf`, safe ones such as `rm -rf dist` included: ask the user to run those.
- Unless opted out, `Read(**/.env.*)` also blocks reading templates such as `.env.example` with the Read tool.
- Keep secrets in environment variables. A test fixture that needs a token-like value takes `acmekit:allow-secret` on its line, and the user confirms each new one.
